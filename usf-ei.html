The Entrepreneurship and Innovation Hub is an on-campus program made by students, for students. The program aims to empower all students, regardless of background, knowledge, and experience, with entrepreneurial skills and opportunities.

My Role

Platform: Mobile and Desktop Web

I was a part of the UX and Web Design Team. Alongside a team of 3 other students, we created the website for the E&I program. Our responsibilities included copy writing, web design, user research, user testing, and incorporating user feedback into design iterations.

User Personas

Phenomaly has 2 types of users. The primary persona is more into capturing them, the secondary is more into learning about them. They both have the same love for monsters, but different capabilities.

App Features

The app allows users to find monsters near them using the interactive map. Users can log their monster hunts by posting them on a feed. If users need help identifying monsters, they can use photo identification, a filter by traits, and a view guide to help.
